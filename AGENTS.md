## Learned User Preferences

- Do not commit, push, or deploy to Vercel unless explicitly asked; production updates when `main` is pushed to GitHub.
- Editorial homepage should lead with the project list, not a hero image or oversized "selected work" headline.
- Gatekeepers belongs last in the portfolio project order.
- Use "visual format experience" branding (including "A v1su4 format experience" under Gods and Gatekeepers).
- Standardize project preview images to one aspect ratio; center-crop for mobile when needed.
- Index hover/preview motion should feel unified, finish before switching targets, and avoid flicker from mismatched image sizes.
- Section headers on the editorial index should match the Lab header treatment (not undersized).
- Bottom contact CTA copy should read like "Let's create something special together" or "Let's create something cool together."
- Glitch index (`/glitch`): keep Manrope only (smaller titles), remove the font picker, and use slimmer split action buttons.
- Editorial "How it works" and stack/build diagrams should follow Project Stack Structure: accent chevron gradients, focal accent nodes, closed isometric cube stacks, compact labels.
- Beta status should allow a short second line (e.g. "In active development"), not wording like "unfinished" or "under construction."
